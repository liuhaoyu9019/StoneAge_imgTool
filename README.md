# 石器时代宠物图片解析工具

面向《石器时代》7.5 客户端资源的浏览器解析器，可从原始 BIN 文件中查找、预览并导出宠物、人物及骑乘形象。解析过程完全在本机完成，资源文件不会上传服务器。

## 支持的资源

| 文件组合 | 内容 | 可导出格式 |
| --- | --- | --- |
| `adrn + real` | 静态图像 | PNG、BMP、批量 ZIP |
| `spradrn + spr` | 动画及帧序列 | 当前帧 PNG、GIF、帧序列 ZIP |

索引文件与像素文件需要成对使用，建议选择前缀或编号一致的文件，例如 `adrn_138.bin` 与 `real_138.bin`。

## 主要功能

- 根据 7.5 客户端配置恢复宠物、人物和骑乘形象名称
- 仅列出可持有宠物与人物，自动排除道具、地图和特效等无关素材
- 输入数字可定位原始图像 ID，输入中文可按名称实时筛选
- 显示图像尺寸、动画组、帧数等资源信息，支持上下张切换和缩放预览
- 静态图默认使用 `PALET_1 + BGR` 还原 7.5 常态配色，并可切换 16 套 SAP 调色板及颜色顺序
- 支持单张、批量和动画导出；大型文件通过 Web Worker 与虚拟列表处理

## 使用方法

1. 将配对的两个 `.bin` 文件拖入上传区，也可以点击上传。
2. 等待索引解析完成，在左侧通过名称或 ID 查找目标。
3. 点击列表条目，在右侧检查形象、配色、尺寸及动画信息。
4. 如颜色异常，可尝试切换调色板或 RGB/BGR 顺序。
5. 按需导出 PNG、BMP、GIF 或 ZIP 文件。

> REAL/ADRN 主要保存像素索引与位置，本身不包含可靠的逐图调色板编号。工具按 7.5 客户端常态规则默认选择配色，其他版本或特殊变色素材可能需要手动切换。

## 本地运行

需要 Node.js 18 或更高版本：

```bash
npm install
npm run dev
```

打开终端显示的本地网址即可使用。执行 `npm run build` 可生成生产版本，执行 `npm run preview` 可预览构建结果。

## 使用限制

- 单个上传文件不超过 1 GB，索引文件不超过 200 MB
- 一次最多上传一组配对文件，批量导出最多选择 2000 项
- 本项目只负责读取与转换资源，不提供游戏客户端文件
